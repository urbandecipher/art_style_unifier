# Art Style Unifier Pro

[繁體中文](README_zh-TW.md) | [简体中文](README_zh-CN.md) | [English](README_en.md) | [日本語](README_ja.md) | [한국어](README_ko.md)

Dark, commercial-style local image style unifier with a multilingual web interface.

## Web Language Options

Open the app in a specific language:

- [Traditional Chinese](index.html?lang=zh-Hant)
- [Simplified Chinese](index.html?lang=zh-Hans)
- [English](index.html?lang=en)
- [Japanese](index.html?lang=ja)
- [Korean](index.html?lang=ko)

The top-right language selector can also switch the page language.

## Features

- Unify multiple target images using one reference image
- Oklab statistical color transfer and histogram matching
- Grain matching and film halation effects
- Surface Blur + Sobel toon-line post-processing
- Draggable Before / After preview
- Single-image or batch PNG download
- Supports Traditional Chinese, Simplified Chinese, English, Japanese, and Korean

## Usage

Open `index.html` directly, or enable GitHub Pages and use it in the browser.

Full instructions are available in `user_guide.html`.
