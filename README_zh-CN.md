# Art Style Unifier Pro

[繁體中文](README_zh-TW.md) | [简体中文](README_zh-CN.md) | [English](README_en.md) | [日本語](README_ja.md) | [한국어](README_ko.md)

深色商业化界面的本机图片风格统一工具，内置多语言网页界面。

## 网页多语言选项

可直接打开指定语言版本：

- [繁體中文](index.html?lang=zh-Hant)
- [简体中文](index.html?lang=zh-Hans)
- [English](index.html?lang=en)
- [日本語](index.html?lang=ja)
- [한국어](index.html?lang=ko)

网页右上角也提供语言切换菜单。

## 功能

- 以一张基准图统一多张目标图的视觉风格
- Oklab 色调统计迁移与直方图匹配
- 颗粒匹配与底片光晕效果
- Surface Blur + Sobel 卡通线条后处理
- Before / After 拖动分割预览
- PNG 单张或批量下载
- 支持繁中、简中、英文、日文、韩文界面

## 使用方式

直接打开 `index.html`，或启用 GitHub Pages 后从浏览器使用。

完整说明请看 `user_guide.html`。
