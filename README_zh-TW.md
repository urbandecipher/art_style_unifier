# Art Style Unifier Pro

[繁體中文](README_zh-TW.md) | [简体中文](README_zh-CN.md) | [English](README_en.md) | [日本語](README_ja.md) | [한국어](README_ko.md)

深色商業化介面的本機圖片風格統一工具，內建多語言網頁介面。

## 網頁多語言選項

可直接開啟指定語言版本：

- [繁體中文](index.html?lang=zh-Hant)
- [简体中文](index.html?lang=zh-Hans)
- [English](index.html?lang=en)
- [日本語](index.html?lang=ja)
- [한국어](index.html?lang=ko)

網頁右上角也提供語言切換選單。

## 功能

- 以一張基準圖統一多張目標圖的視覺風格
- Oklab 色調統計遷移與直方圖匹配
- 顆粒匹配與底片光暈效果
- Surface Blur + Sobel 卡通線條後處理
- Before / After 拖曳分割預覽
- PNG 單張或批次下載
- 支援繁中、簡中、英文、日文、韓文介面

## 使用方式

直接開啟 `index.html`，或啟用 GitHub Pages 後從瀏覽器使用。

完整說明請看 `user_guide.html`。
